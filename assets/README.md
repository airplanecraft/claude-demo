# Assets 目录说明

此目录用于存放 Manim 视频生成所需的静态资源文件。

## 必需文件

### 1. logo.png
- **用途**：显示在视频左上角的 Logo
- **建议尺寸**：任意尺寸（代码中会自动缩放到 0.15 倍）
- **推荐尺寸**：200 × 200 像素或更高
- **格式**：PNG（支持透明背景）
- **显示位置**：视频左上角（解题阶段贯穿始终）

### 2. cover.png
- **用途**：封面阶段的背景图
- **建议尺寸**：1920 × 1080 或更高（将自动拉伸到全屏）
- **格式**：PNG 或 JPG
- **显示时长**：视频开头 3 秒
- **显示内容**：作为封面背景，中央会叠加原题图片和题号标签

## 文件位置

请将这两个文件直接放在 `assets/` 目录下：

```
assets/
├── README.md     (本文件)
├── logo.png      (需要您提供)
└── cover.png     (需要您提供)
```

## 视频布局说明

生成的视频分为两个阶段：

### 封面阶段（3秒）
- 全屏显示 `cover.png` 作为背景
- 中央显示原题图片（4.0 × 3.0 大小）+ 题号标签（Q）
- 底部显示比赛信息文字（如：2025香港袋鼠数学竞赛）

### 解题阶段
```
┌─────────────────────────────────────────┐
│ [Logo]                                  │
│                                         │
│  ┌─────────┐     ┌──────────────┐     │
│  │         │     │              │     │
│  │  原题   │  │  │  动画演示区  │     │
│  │  图片   │  │  │  (右上方)    │     │
│  │         │  │  │              │     │
│  └─────────┘  │  └──────────────┘     │
│               │                         │
│               │  ┌──────────────┐     │
│               │  │ 解题步骤1    │     │
│               │  │ 解题步骤2    │     │
│               │  │ 解题步骤3    │     │
│               │  └──────────────┘     │
│               │                         │
│  [答案显示在左侧原题下方]              │
│                                         │
│ [底部字幕条 - 语音文字]                │
└─────────────────────────────────────────┘
```

- **左侧**：原题图片固定显示，下方显示最终答案
- **右侧上方**：动画演示区域
- **右侧下方**：解题步骤（三个一组滚动显示）
- **底部**：实时语音字幕

## 注意事项

- 如果缺少这些文件，视频生成仍会继续，但会显示默认占位符
- Logo 在解题阶段会持续显示在左上角
- 封面背景只在视频开始的前 3 秒显示
- 原题图片存放在 `input/images/` 目录，不在此目录
- 建议使用高质量图片以获得最佳视觉效果
