# Assets 目录说明

此目录用于存放 Manim 视频生成所需的静态资源文件。

## 必需文件

### 1. logo.png
- **用途**：显示在视频左上角的 Logo
- **建议尺寸**：任意尺寸（代码中会自动缩放到 0.15 倍）
- **格式**：PNG（支持透明背景）

### 2. cover.png
- **用途**：封面阶段的背景图
- **建议尺寸**：1920 × 1080 或更高（将自动拉伸到全屏）
- **格式**：PNG 或 JPG

## 文件位置

请将这两个文件直接放在 `assets/` 目录下：

```
assets/
├── README.md     (本文件)
├── logo.png      (需要您提供)
└── cover.png     (需要您提供)
```

## 注意事项

- 如果缺少这些文件，视频生成仍会继续，但会显示默认占位符
- Logo 会显示在视频的左上角
- 封面背景会在视频开始的前 3 秒显示
- 原题图片存放在 `input/images/` 目录，不在此目录
