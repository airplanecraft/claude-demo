# 第二阶段：数学求解

## 任务
给出详细的、分步骤的解题逻辑，确保答案准确。

## 要求

### 1. 题目分析
- 仔细理解题目要求
- 识别关键信息和已知条件
- 明确需要求解的问题

### 2. 解题思路
- 说明采用的解题方法
- 解释为什么选择这种方法
- 列出主要步骤概览

### 3. 详细步骤
每一步都要包含：
- **步骤说明**：清晰描述当前步骤在做什么
- **数学推导**：展示具体的计算或推理过程
- **关键点**：标注重要的数学性质或技巧
- **中间结果**：给出每步的结论

### 4. 答案验证
- 检查答案的合理性
- 如果可能，用其他方法验证
- 确认答案符合题目要求

### 5. 答案总结
- 明确给出最终答案
- 说明答案的单位（如果有）
- 简要总结解题要点

## 输出格式示例

```
【题目分析】
...

【解题思路】
...

【详细步骤】
步骤1：...
- 推导：...
- 关键点：...
- 结果：...

步骤2：...
...

【答案验证】
...

【最终答案】
...
```

## 注意事项
- 后续的 Manim 动画和 JSXGraph 交互都必须严格基于此解题步骤进行演示
- 解题步骤要详细到可以直接用于编写动画代码
- 每个关键步骤都应该可以对应到一个视觉呈现
